# Cross-check against the handoff figures

The five images in `figures/` were checked on 2026-11-16 against the code, the database and the
plan. Each box of the two architecture diagrams is listed with what actually exists and the
sub-step that closes any gap. Gaps found here were added to `IMPLEMENTATION_PLAN.md`.

## 1. Result figures: numbers verified against `experiments/results/`

`baseline-results.png`, `calibration.png` and `confusion-matrix.png` were compared value by
value with `metrics.json` and `per_class.csv`. All agree.

| Shown in the figures | In the stored results | Match |
|---|---|---|
| Train / validation / test sizes 70,119 / 14,918 / 14,963 | same | Yes |
| Test top-1 15.71 %, top-3 39.67 %, macro F1 0.115, ECE 0.613 | 0.1571, 0.3967, 0.115, 0.613 | Yes |
| Majority baseline 20.6 % | 0.2056 | Yes |
| Label coverage 39 of 46; seven labels with no test rows | 39 present; the same seven labels have support 0 | Yes |
| Feature masking 15.7 / 16.6 / 17.6 / 19.7 % at 100 / 75 / 50 / 25 % observed | same | Yes |
| Learning curve 19.2 / 16.7 / 16.3 / 15.7 % at 7,011 / 17,529 / 35,059 / 70,119 rows | same | Yes |
| Largest confusions (Asthma → SLE 330, … Asthma → Type2 Diabetes 227) | same five | Yes |
| Top-confidence bin: 6,048 examples, 97.48 % confidence, 19.58 % correct | 6048, 0.9748, 0.1958 | Yes |

What this does **not** establish: the experiment has not been re-run in this repository (M4.1).
The figures also show two anomalies that M4 must investigate rather than tune around: accuracy
*rises* when features are hidden, and *falls* as training data grows. Both suggest the
archive-11 labels are only weakly related to its features. The figures' own conclusions are
already enforced in code: the baseline is not wired into serving and no score is shown to users.
